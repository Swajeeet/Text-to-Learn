# Text-to-Learn

An AI-powered course generation platform built on the MERN stack. Enter any topic and get a fully structured course with lessons, YouTube video recommendations, PDF export, and Hinglish translation — all generated by AI.

---

## Features

- **AI Course Generation** — Full course structure generated via Google Gemini / OpenRouter
- **YouTube Integration** — Relevant video embeds fetched per lesson via YouTube Data API
- **PDF Export** — Download any generated course as a formatted PDF
- **Hinglish Translation** — One-click translation of course content to Hinglish
- **JWT Authentication** — Secure register / login with protected routes
- **My Courses** — Save and revisit previously generated courses
- **Rate Limiting & Helmet** — Production-grade security middleware

---

## Tech Stack

| Layer      | Technology                          |
|------------|-------------------------------------|
| Frontend   | React 18, Vite, React Router v6     |
| Backend    | Node.js, Express 5                  |
| Database   | MongoDB Atlas, Mongoose             |
| AI         | Google Gemini API, OpenRouter API   |
| Auth       | JWT (jsonwebtoken, bcryptjs)        |
| Video      | YouTube Data API v3                 |
| PDF        | PDFKit                              |
| Security   | Helmet, express-rate-limit          |

---

## Architecture

```
Text-to-Learn/
├── client/          # React + Vite frontend
└── server/          # Express REST API backend
```

The client communicates with the server via a REST API (`/api/v1`). The server handles authentication, AI generation, YouTube search, PDF export, and all database operations.

## Installation

### Prerequisites

- Node.js ≥ 18
- MongoDB Atlas account
- Google Gemini API key
- OpenRouter API key
- YouTube Data API v3 key

### Clone

```bash
git clone https://github.com/Swajeeet/Text-to-Learn.git
cd Text-to-Learn
```

### Install dependencies

```bash
# Server
cd server
npm install

# Client
cd ../client
npm install
```

---

## Environment Variables

### Server — `server/.env`

Copy `server/.env.example` to `server/.env` and fill in your values:

```env
PORT=5000
MONGODB_URI=YOUR_MONGODB_URI
AUTH0_DOMAIN=YOUR_AUTH0_DOMAIN
AUTH0_AUDIENCE=YOUR_AUTH0_AUDIENCE
GEMINI_API_KEY=YOUR_GEMINI_API_KEY
OPENROUTER_API_KEY=YOUR_OPENROUTER_API_KEY
JWT_SECRET=YOUR_JWT_SECRET
JWT_EXPIRES_IN=7d
YOUTUBE_API_KEY=YOUR_YOUTUBE_API_KEY
```

### Client — `client/.env`

Copy `client/.env.example` to `client/.env`:

```env
VITE_API_URL=http://localhost:5000/api/v1
```

## Running the App

### Start the server

```bash
cd server
npm run dev
```

Server runs on `http://localhost:5000`

### Start the client

```bash
cd client
npm run dev
```

Client runs on `http://localhost:5173`
